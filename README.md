# Banking Interest Simulator (Yearly Interest)

## 📌 Project Details
This mini project is a simple C program that simulates yearly banking interest calculations.  
The user enters the **principal amount**, **annual interest rate**, and **number of years**.  
The program then applies compound interest year by year and outputs the **final balance** after the specified duration.

---

## 🎯 Why This Project
The project was created as part of an end‑semester mini project to:
- Practice **C programming fundamentals** (loops, arithmetic operations, user input).
- Understand how **banking interest calculations** work in real life.
- Gain hands‑on experience with **VS Code** and **GitHub** for development and version control.

---

## ⚙️ Utility
- Helps students and beginners understand **compound interest** in a practical way.  
- Can be extended to simulate different banking scenarios.  
- Provides a clear example of **step‑by‑step programming logic** in C.
